# Whole-tumour population-graph manuscript

*Tumour definition, not the patient graph, determines the external discrimination of radiomics-based
population graph neural networks for outcome prediction in head and neck cancer.*

| File | Content |
|---|---|
| `main.tex` | the manuscript (A4 article layout, Nature-style numbered references) |
| `supplementary.tex` | Supplementary Information: Tables S1–S2 and the TRIPOD+AI, CLAIM 2024, CLEAR, METRICS and RQS checklists (Tables S3–S7) |
| `scripts/make_checklists.py` | writes `tables/tabS_checklists.tex` (checklist items, METRICS and RQS scores) and `tables/table_reporting.tex` (summary table in the main text) |
| `references.bib` | bibliography; check every entry against the publisher record before submission |
| `figures/` | all figures (generated by `scripts/make_assets.py`) |
| `tables/` | all tables + `numbers.tex` (every number quoted in the text, as LaTeX macros) |
| `scripts/make_assets.py` | regenerates `figures/` and `tables/` from `grafs-gat/outputs/popgraph/results/` and `grafs-gat/outputs/gtv_only/results/classical_total_*` |
| `sn-jnl.cls` | Springer Nature class, kept for a journal-formatted version |

## Compile
Overleaf: upload the folder as a zip, `main.tex` is the main document (pdfLaTeX → BibTeX → pdfLaTeX ×2).
Locally: `tectonic main.tex` and `tectonic supplementary.tex` (or `latexmk -pdf`).

## Regenerate after a re-run
```bash
cd grafs-gat
POPGNN_CLIN=burden POPGNN_FEAT=total python popgraph/run_popgnn.py        # main grid (and the 3 ablation variants)
python popgraph/graph_vs_mlp.py --prefix popgnn_burden_total               # graph vs no-graph selection
POPGNN_CLIN=burden POPGNN_FEAT=total python popgraph/seed_robustness.py    # seed re-runs
cd gtv_only && CLS_FEAT=total python run_classical.py                      # conventional classifiers
cd ../.. && python Paper/manuscript_popgraph/scripts/make_assets.py         # tables, figures, numbers.tex
```
The tables, figures and every number in the text update automatically; re-read the Results and
Discussion wording afterwards, because the direction of a finding may change.
